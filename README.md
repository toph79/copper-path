# Copper Path

PCB design lessons as an installable web app: 400 lessons, each citing one source page, with streaks, Daily Charge, Arena and badges. Runs offline once loaded; progress is saved on the device (Badges tab → Export/Import backup).

**Install:** open the site on your phone → Share → *Add to Home Screen* (iPhone, Safari) or ⋮ → *Install app* (Android, Chrome).

**Host:** Settings → Pages → Deploy from branch → `main` / root.
